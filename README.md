# PV-Power-Machine-Learning-Pipeline

This is a machine learning project that I completed with Dr. Hafeez, a professor in machine learning and AI at the Jubail Industrial College. The main goal of this project was to touch base with basic machine learning concepts through a project lens rather than an academic lense. While extensive research was required for understand solar physics, the main objective was to lean different types of ML models and evaluate the sustainability of main machine learning algorithms, them being Linear Regression, random forest and XGBoost. 

I also learned what evaluation metrics are used in machine learning for assessment including Mean Absolute Error, Root Mean Squared Error and Coefficient of Determination. More information on the physics and coding concepts can be found in "DRAFT Solar Photovaltic Power Forecast Report". 

Summary for important concepts: 
* Machine learning has three important components: supervised learning, unsupervised learning and reinforcement learning 
* Linear Regression is the algorithm that assumes there is a linear relationship between x and y (uses scikit-learn library).
* Random Forrest is the algorithm that (to put it simply) combines multiple predictions, so it uses a more randomness model (also uses scikit-learn library).
* XGBoost is the algorithm that combines multiple smaller trees or weaker models to create one big efficient predictive model.
* Mean Absolute Error (MAE) is a formula used to measure the accuracy of said algorithm. 
* Root Mean Squared Error (RMSE) is the square root of the MAE, measuring the magniute of error. 
* Coefficient of Determination R^2 is the statistic percentage score that measures how well the ML algorithm predicts the outcome (ie if R^2 = 1.000 then perfect).
